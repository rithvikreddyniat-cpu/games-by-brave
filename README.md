# SNAKE NOIR — The Unprinted Panel

An interactive 1950s detective comic book game where you control Detective Snake, exploring an unprinted, pitch-black comic panel to illuminate hidden crime scene evidence, reconstruct a noir mystery, and confront a dramatic dark rule-reversal twist where your own movement destroys the truth.

---

## 🎮 How to Play

- **Move Detective Snake**: `W` `A` `S` `D` / `Arrow Keys` / `Mobile Touch Swipe` / `Virtual D-Pad`
- **Case Board**: Press `C` to view discovered evidence, lost clues, and theory chronology.
- **Reconstruct Crime**: Press `R` to open the Reconstruction Theory modal once enough evidence is illuminated.
- **Action / Confirm**: Press `SPACE` or `ENTER` to start the case, confirm choices, or advance final revelation panels.

---

## 🛠️ How to Run Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

---

## 📦 How to Build for Production

1. **Compile Production Bundle**:
   ```bash
   npm run build
   ```

2. **Deploy to itch.io**:
   - Zip the **CONTENTS** of the `dist/` directory (ensuring `index.html` resides directly at the root of the ZIP file, e.g., `snake-noir-itch.zip`).
   - Note: `dist/` is ignored by `.gitignore`.
